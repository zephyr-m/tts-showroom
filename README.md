# Верстак

Стеклянный верстак для TeraTTSv2. Один экран. Исходники для этой схемы не нужны.

Предмет — текст слева. Строка текста — дубль. Вставка режется по переводам строк и по `.!?…`.

Конвейер под кнопкой «Собрать цепочку». Шаг — строка, дубль — столбец. Шаги Tera лежат один раз:

1. Текст после ударений
2. Индексы символов
3. Стиль голоса
4. Эмбеддинг текста
5. Длительность
6. Стартовый шум
7. Латент сэмплера
8. Волна вокодера

Новый дубль дописывается вправо в каждый шаг. В ячейке артефакт шага и его время. Старые дубли остаются. Новый запуск кнопки очищает ленты один раз.

Пульт: голос, скорость (0.75–1.35, по умолчанию 1.15, больше — медленнее), зерно, примесь голоса и её доля.

Зашито в прогоне и не вынесено ручкой: guidance 3.0, делитель длины 1.05, кадр латента 3072 отсчёта при 44100 Гц. 1.05 и 3072 написаны на шаге «Длительность». Guidance на карточке нет.

Результат — плеер справа от текста. Дорожка и волна на дубль. Старт с первого готового, остальные дописываются. У списка нет своего скролла.

Рядом в том же сервере есть vosk-tts и edge-tts. Рабочий конвейер — Tera.

Правило типа. Шаг — строка, дубль — столбец. У каждого параметра своё место: редактируемый — ручка, зашитый — число. Для другой библиотеки называй её в первом предложении и подставляй её шаги в конвейер.
